# 🚆 NIT RailGuard Project 

NIT RailGuard is a smart railway safety and monitoring platform designed to improve railway security and provide better assistance during emergencies.

## 📌 About The Project

NIT RailGuard is a web-based application built using modern web technologies. It focuses on railway safety, monitoring, and quick response to suspicious or emergency situations.

The project provides a simple and user-friendly interface for accessing important railway safety features.

## ✨ Features

- 🚆 Railway safety monitoring

- 🚨 Emergency assistance

- 🔍 Suspicious activity monitoring

- 📍 Location-based information

- 👤 User-friendly dashboard

- 📊 Simple and responsive interface

- ⚡ Fast and modern web application

## 🛠️ Tech Stack

- React.js

- Vite

- JavaScript

- Tailwind CSS

- HTML5

- CSS3
